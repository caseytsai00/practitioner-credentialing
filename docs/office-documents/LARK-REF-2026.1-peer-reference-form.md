# **Professional peer reference — blank request and return form**

Larkhollow Community Hospital · Medical Staff Office Form version **LARK-REF-2026.1**.

The office sends this form directly to the referee the applicant named, and the referee returns it directly to the office. **A form that reaches us through the applicant cannot be used.**

## Part 1 — completed by the Medical Staff Office before sending

|  |  |
| :-: | :-: |
| Field | Content |
| Referee identifier | The office's identifier for this referee on this file |
| Applicant | Name and degree |
| Privileges requested | The privilege groups on the application |
| Request date | The date this request was sent |
| Request number | 1, 2 or 3 — each reminder is a fresh numbered request |

We write up to three times, 21 calendar days apart. If no reply has reached us by the 64th day after the first request, we tell the applicant and ask for an additional referee. **The original request stays open.** We do not close it as satisfied and we do not count it.

## Part 2 — completed by the referee

|  |  |
| :-: | :-: |
| Field | What to enter |
| Are you a relative, spouse or partner of the applicant? | Tick Yes or No. This box is never left blank |
| Relationship | How you worked with the applicant, in your own words |
| Your specialty | The clinical discipline you practise, chosen from the same list the applicant chose from: Family Medicine, Internal Medicine, Hospital Medicine, Cardiovascular Disease, Emergency Medicine, General Surgery, Obstetrics and Gynecology, Pediatrics, Anesthesiology, Diagnostic Radiology, Psychiatry, Orthopaedic Surgery — or your own discipline if it is not on that list |
| Dates you worked directly together | First and last date. **Leave the last date blank only if you still work together** |
| Recommendation | Recommend without reservation, Recommend, Recommend with reservations, or Do not recommend |
| Comments | Character, clinical experience, competency, and anything else you want on the record |
| Signature and **signature date** | The date you sign. This is the date we measure currency from — not the date we receive the form |

### Who may give a peer reference

Three conditions, each independent, all three required:

1. you have **worked directly with the applicant within the two years ending on the day you sign this form**;
2. you practise in the **same clinical discipline** as the applicant;
3. you are **not a relative, spouse or partner** of the applicant.

If any one of the three does not hold, say so on the form and return it anyway. We will record your reply, and we will not count it towards the two references the appointment needs. That is not a judgment about you or about the applicant; it is the rule we apply to every file the same way.

### Currency

A reference is current if the **signature date** is within two years of the date the file is presented to the Governing Body. A reference signed a long time before the file is presented stops being current, and we ask again.

## Part 3 — completed by the Medical Staff Office on return

|  |  |
| :-: | :-: |
| Field | Content |
| Received date | The date the completed form reached the office |
| How it arrived | Secure portal, letter, fax or email, direct from the referee |

Nothing in Part 2 is edited, summarized or corrected by the office. What the referee wrote is what goes in the file, including a relationship or a specialty that differs from what the applicant told us.
